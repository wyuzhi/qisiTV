# 画布便签（`sticky-note`）

## 适用场景

- 用户提出“帮我贴个便签”“记一下这几条修改意见”“把待办列成便签放画布上”。
- 用户要求更新画布上已有的便签内容或标题。

## 操作步骤

1. 将用户口述或讨论的要点拆成简洁清晰的条目，每张便签聚焦一个要点。
2. 新建便签时调用 `sticky_note_create`，传入 4 至 12 字的概括 `title` 和正文 `text`。
3. 修改已有便签时调用 `sticky_note_update`，传入目标 `nodeId` 以及更新后的 `title` 或 `text`。
4. 完成后告知用户新建或更新了几张便签。
