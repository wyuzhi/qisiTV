# AIHubKit Video（`beeftv-plugin-aihubkit-video`）

该目录是 BeefTV 统一 npm 插件包格式的声明式视频渠道协议插件，通过 `package.json` 的 `beeftv.contributes.providers` 声明 `aihubkit-video` 视频生成与轮询协议，不依赖系统内置 `host:` 适配器。

本插件由社区贡献者维护，用于适配 AIHubKit 相关服务接口；不表示 BeefTV 与该服务商存在隶属、授权或合作关系。

完整接口说明见 [docs/interface.md](docs/interface.md)。
