## 适配内容

- 新插入的引用保存具体素材身份，提交时转换为模型所需的编号；调整连线后保持原素材指向。旧的手写编号继续按位置解释，普通数字不自动变成素材引用。
- 视频生成前校验素材表与实际参考顺序；角色的图片和声音按最终槽位绑定。保留源素材名称显示、浏览器本机资源读取和外部 MCP 写入。
- 视频提示词不再一律新增 8000 字符上限，按模型与接口合同校验；已有用户保存的限制继续生效。不截断提示词，不把 BeefAPI 的限制套到 LikeAI / qisi API。
- 视频失败后优先检查保存的任务，避免从后来修改的画布静默重建原任务。桌面端通过后端重试原任务快照；网站端查询并恢复原任务结果，失败时明确提示用户从输入节点发起新生成。网站不新增自动收费重试，不保存完整敏感请求或密钥来模拟重放。
- 网站取消等待后仍可取回上游已完成的原视频；重复点击及切换项目期间的迟到响应受到保护。
- 补齐 qisiTV 适配回归：身份引用紧贴中文或英文时仍带上参考素材，整组复制与跨画布粘贴精确重映射引用；本机恢复错误直接显示在节点中，素材表校验失败显示可见对话框。

## 保留范围

保留本机独立项目文件夹、qisiTV 品牌、qisi API / LikeAI 独立配置、外部 MCP 和 WorkBuddy 紧跟 Codex 的顺序。MCP 程序保持 0.3.0，无需重新安装。

本次不是 BeefTV v2.0.3 全量升级。上游内置助手、技能市场、可复用工作流和 Topaz 超分依赖其另一套桌面运行时与服务。本次未引入这些模块，也未加入钱包或网页登录。
