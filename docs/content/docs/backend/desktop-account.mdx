点击侧栏底部与更新、主题切换按钮同一行的 **登录 BeefTV** 打开账户设置弹窗，在「账号与余额」中点击 **登录** 按系统浏览器提示登录官方账户并完成授权。返回应用后，官方模型渠道会自动同步到本地，无需保持模型配置页打开。关闭账户弹窗后授权仍会继续，侧栏会显示账户名称或等待确认状态。模型同步失败时可在账户弹窗中重试。

模型配置页内置 **BeefTV** 的 **连接 BeefTV** 与侧栏共用同一连接。点击侧栏账户可在四个分类中管理常用功能：

- **账号与余额**：查看账户身份与余额，选择固定充值金额或自定义金额，进入购买确认并选择支付方式。当前充值为前端预览，支付入口明确标记暂未开放，不创建订单、不扣款、不修改余额。具体余额与用量仍可在官网查看；本地不计算或估算余额。登录后的官方模型同步自动进行，此页不再显示连接说明或断开入口。
- **通用设置**：选择浅色、深色或跟随系统外观，查看当前版本、更新日志与第三方许可，进入存储设置或连接诊断。跟随系统会随系统明暗变化自动更新，并在重启后保留；手动切换外观后停止跟随。
- **模型**：选择各类默认模型，管理现有模型渠道。设置与模型配置页保持同步。
- **内置插件**：以每行两张卡片展示随应用提供的插件，可搜索、查看权限与版本，并按后端允许的范围启停；窄屏自动切为单列。简介默认显示两行，展开插件信息可阅读完整内容。其他插件仍在插件页管理。

连接的授权、账号与钱包入口统一使用 `https://beeftv.app`。

内置渠道 ID `beeftv`、凭据引用 `beeftv` 与客户端 ID `beeftv-enterprise-v1` 固定使用官方算力连接配置。托管 Key 只在本地后端解密，前端接收脱敏状态和模型目录。恢复连接只信任明确的生产源 `https://beeftv.app`；本地联调源必须显式配置。

## 连接网络与失败提示

账号授权请求默认跟随 Windows/macOS 当前用户的静态系统代理及排除地址规则；没有代理时直接连接。非空 HTTP/HTTPS 环境代理优先，且不会被自动绕过；启动器传入的空代理值不覆盖系统配置。需要明确直连时可设置 `NO_PROXY=*`。修改系统代理后重试会读取新配置。

使用系统代理时，如果 HTTPS 连接尚未建立便发生拨号失败或握手超时，应用尝试直接连接一次，并显示“正在尝试其他连接方式”。已经建立连接、收到服务器响应、证书校验失败或请求被取消时，不换路线重发。此重试仅用于账号授权请求，不用于生成或扣费。

连接状态中的 `connecting` 表示正在建立授权连接，`connection_error` 表示无法建立连接或服务端未接受授权请求；`errorReason` 提供不含凭据的用户提示。`store_error` 只用于本地连接状态或密钥保存、读取失败。网络失败不会再显示为“保存连接失败”。

前端“开始连接”请求等待 35 秒，覆盖后端 30 秒网络预算；其余本地请求保持原超时。请求失败后重新读取本机连接状态，仍在进行的授权继续查询。授权查询断网时显示“连接中断，正在重试”；完成授权后等待服务端确认时显示“正在完成连接确认”，不继续要求用户重复确认。服务端确认重试耗尽后进入 `connection_error`，提示“连接确认失败，请重试”；重新连接会继续确认已保存的凭据，无需重新浏览器授权。
