# 网站版与浏览器本地保存

网站版挂载在 `/qisitv/`，直接在浏览器里打开。不需要注册、登录或启动 Go 服务；画布、版本、素材、生成任务和 LikeAI 配置保存在当前浏览器的 IndexedDB 中。清除网站数据、使用无痕模式或换浏览器不会自动保留这些内容，请定期使用画布导出功能备份。

## 使用

1. 在网站进入「qisiTV 起司 TV」，创建画布并导入参考素材。
2. 在设置中填写自己的 LikeAI API Key，拉取模型。
3. 选择图片、视频等节点，连接参考素材，填写提示词后手动生成。

界面只提供 LikeAI。旧工作区中的其他服务商记录保留在原始本地数据中，避免破坏历史配置，但不作为当前可用渠道显示或执行。

## 请求与保存

LikeAI 接口没有开放浏览器跨域请求，因此网站提供固定目的地的 `/api/qisitv/likeai/` 转发。密钥、提示词与本次参考素材会经过网站函数，再发给 LikeAI；应用不在网站服务器建立账号、数据库或素材存储，不记录请求正文和密钥。LikeAI 自身的任务和临时素材保留规则由服务商决定。

生成意图先写入浏览器，再提交一次。刷新后有供应商任务编号的任务只继续查询，不自动重新生成。提交中断且没有取得任务编号时，会提示到 LikeAI 核对，不自动重试或扣费。生成完成后尝试保存媒体到浏览器；下载失败会保留原结果链接并明确显示「本地保存未成功」。

网页上传的单个参考文件上限为 4,000,000 字节；较大的参考素材需使用服务商可访问的 HTTPS 地址。网站转发只接受明确列出的 LikeAI 路径，不接受任意上游地址。结果下载通过任务编号查询并验证来源，不会把 API Key 发给媒体 CDN。

## 构建到网站

在仓库根目录运行：

```bash
./scripts/export-qisitv-website.sh /absolute/path/to/personal-site
```

脚本设置 `VITE_QISITV_BROWSER_ONLY=1` 和 `QISITV_WEB_BASE=/qisitv/`，构建前端并复制到 Astro 网站的 `public/qisitv/`，同时复制 `deploy/website/` 中的转发函数并合并对应 Vercel 路由。网站目录需要已有 `vercel.json`；部署前用 `vercel build` 验证函数与静态站点。网站版采用 hash 路由，画布地址形如 `/qisitv/#/canvas/ID`；静态资源也使用此子目录前缀。默认桌面构建仍使用原本地服务。

## Codex 与本地程序

现有 MCP/CLI 连接的是本机 Go 工作区，详见[本地 Agent](/docs/backend/local-agent)。它不能直接读取网站源下的浏览器 IndexedDB。网站中的画布与原桌面画布也不会自动合并。

当前网站版关闭内置 Agent 对话及对 Go 的后台轮询。需要现有 Codex 控制能力时，使用本地程序的画布工作区。网站画布与本地程序之间的显式配对、同步尚未接通，不能将启动 MCP 视为已经连接了网站画布。
