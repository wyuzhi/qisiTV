# 本地后端代码地图

qisiTV 是单用户、本地优先的桌面应用。项目、画布、素材、任务和 Agent 状态落到本地 SQLite 与工作区目录；模型生成仍可通过 Provider/Protocol 适配器访问外部 API。

## 运行链路

```text
Wails / local dev
  -> internal/bootstrap        组合根、数据库、HTTP 生命周期
  -> internal/localapp        本地能力端口
  -> internal/{task,asset,project,workspace}
  -> internal/app             跨域编排与尚未拆分的核心实现
  -> internal/{generation,provider,protocol,outbound}
  -> external model APIs
```

## 主要目录

| 边界 | 位置 | 职责 |
| --- | --- | --- |
| 组合根 | `backend/internal/bootstrap` | 打开本地数据、组合窄服务、启停 HTTP 与 worker |
| 本地应用 | `backend/internal/localapp` | 定义 workspace/project/asset/task/generation/provider-config 端口 |
| 任务域 | `backend/internal/task` | 本地任务命令、列表读模型和生命周期边界 |
| 生成域 | `backend/internal/generation` | 统一生成输入、引用、能力、协议调度和失败归类 |
| 供应商适配 | `backend/internal/provider`, `protocol`, `outbound` | 外部模型 API、自定义渠道和插件协议 |
| 数据 | `backend/internal/database`, `repository` | SQLite schema、迁移和持久化 |
| HTTP | `backend/internal/handler` | 本地 `/api` 合同、输入限制和响应封装 |
| 企业连接 | `backend/internal/beefapi` | 设备授权、本机密钥和连接状态 |
| 本机 MCP | `backend/internal/mcp` | 进程内 initialize / tools/list / tools/call |
| 外部 Agent | `backend/internal/agentbridge`, `backend/cmd/mcp`, `backend/cmd/qisitv` | 官方 SDK MCP stdio 与 CLI，共享校验和现有工作区 HTTP 操作 |
| 桌面更新发布 | `backend/cmd/update-release` | 生成更新密钥、打包 zip、签署 `desktop-update.json` |
| 前端 | `web/src` | React 画布、项目、素材、模型配置与插件 UI |

## 硬边界

- 不提供登录、注册、计费、支付、公开分享或云存储路由。
- 内置 BeefAPI 密钥保存在本机加密连接存储中；其他手动渠道密钥仍在本地模型配置中。密钥不进入画布快照或日志响应。
- 外部 API 是生成能力，不是 SaaS 数据面；不得在“本地化清理”中删除 Provider、Protocol、自定义渠道或插件扩展点。
- worker 并发策略由任务运行时管理，架构整理不得顺带改变其行为。

HTTP 稳定合同见 [HTTP API](/docs/backend/http-api) 和 `backend/internal/handler/openapi.yaml`。
