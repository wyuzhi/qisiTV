# 插件系统怎么运转

这一页写给改 BeefTV 代码的人。要写插件，看[开发一个插件](./plugin-development.mdx)。

一个插件就是一个 npm 包，一个 pi 包加上 `package.json` 的 `beeftv` 字段。下面这些内容都只有一份：

| 内容 | 唯一来源 |
| --- | --- |
| 清单校验 | Go `internal/protocol` 和 `internal/plugins`，`.beeftv-plugin` 和 npm 包走同一个校验器 |
| 装了哪些插件、启用状态、加载错误 | Go 的 `plugin_registry`。`agent-host` 和前端只从后端读 |
| 画布节点类型 | `capability.BuiltinRegistry()`。手动添加和助手调用 `canvas_nodes_create` 用同一份尺寸、连线和字段校验 |
| 业务写入 | `/api/ops`。权限模式、付费确认和整组撤销都在后端 |
| 技能 | `internal/skills`。`pi.skills` 登记进安装包体系，来源记为对应插件 |

## 安装

1. 用户在安装确认框里确认。第三方插件要勾选「我了解风险」。
2. Go 用自带的 node 和 npm 执行 `npm install --prefix`，依赖一起装到暂存目录。npm 源只允许 npmmirror 和 npmjs。
3. Go 校验清单，事务提交后才替换旧版本，失败时旧版本不受影响。
4. 从本地目录安装时，BeefTV 复制这个目录，并记住原路径。「重新加载」就是重新复制一次。

`.beeftv-plugin` 是 BeefTV 自带模型协议的打包格式，根目录是 `manifest.json`，不能带代码。

## 加载

| 部分 | 谁来加载 | 什么时候生效 |
| --- | --- | --- |
| `beeftv.client` | 浏览器动态加载，调用 `activate(host)`。超过 15 秒或出错只把这个插件标为异常 | 立即 |
| `pi.extensions` | `agent-host` 用官方 `DefaultPackageManager` 和 `discoverAndLoadExtensions`，只加载 Go 下发的已启用插件目录 | 下一轮对话 |
| `pi.skills` | Go 登记，助手沿用原有的技能版本固定和 `skill_load` | 下一轮对话 |
| JSON 生成服务 | Go `internal/protocol`，请求由 Go 发 | 立即 |
| JS 生成服务 | `internal/pluginhost` 启动一个 Node 子进程运行 `agent-host/plugin-host.mjs`，按行收发 JSON | 下一次调用 |

JS 生成服务不放进助手进程：助手进程要配好助手模型才启动，换模型时还会重启，生成任务不能受这些影响。任务规则在 `generation/module_provider.go`，和 JSON 协议相同：先记任务号再查询，提交结果不明时不重发，重启后只查询。

插件文件由 Go 提供，只开放登记表里这个插件目录下的静态文件，越界或访问 `node_modules` 一律返回 404。

## 信任

BeefTV 不做沙箱，也不审核插件。`client` 和 `pi.extensions` 和 BeefTV 有同样的本地权限，`module` 能拿到用户填给这个服务的 Key。保护用户的是安装前的确认：每次安装和更新都显示来源、版本和风险。

精选列表公开在 `Sunnyender-org/beeftv-plugins`。插件市场固定提示收录不代表担保。

## 更新

- `GET /api/plugins/updates` 比较已安装版本和 npm 或精选列表上的版本，插件中心据此显示「更新到 vX」。
- 精选列表 `plugins` 里带 `tarball` 和 `sha256` 的条目由 BeefTV 维护。后端启动一分钟后检查一次，之后每 6 小时检查一次，有新登记的版本就自动更新，并校验 `sha256`。
- 精选列表 `packages` 里只写 npm 包名，卡片信息从 npm 读，由用户自己更新。

## 自带的插件

| 插件 | 位置 | 说明 |
| --- | --- | --- |
| `beeftv-plugin-market`、`beeftv-plugin-ll2` | `plugin-packages/`，列在 `bundled-plugin-dirs.txt` | 随安装包预装并默认启用 |
| 提示词优化器、Eagle 素材库、AI 审美批改、媒体转换、剪辑工作台 | `web/src/lib/plugins/builtin/` | 内置功能，和插件走同一套挂点 |
| `beeftv-plugin-character-replacement`、`beeftv-plugin-comfyui`、`beeftv-plugin-runninghub` 等 | `plugin-packages/` | 在线安装，不随安装包附带 |
| `beeftv-plugin-sticky-note`、`beeftv-plugin-ecommerce-hero` | `plugin-packages/` | 开发样板 |
| `beeftv-plugin-slot-test` | `plugin-packages/` | 每个挂点各挂一项的开发自检，不进精选列表，也不随安装包附带 |
