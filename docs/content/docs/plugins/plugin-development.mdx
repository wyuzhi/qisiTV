# 开发一个插件

一个插件就是一个 npm 包：一份普通的 `package.json`，加一段 `beeftv`。不用打包工具，也不用申请，写完就能装。

## 五分钟做出第一个插件

这个插件在命令面板里加一条命令，选中后弹出一句问候。

**1. 新建文件夹 `beeftv-plugin-hello`，放两个文件。**

`package.json`：

```json
{
  "name": "beeftv-plugin-hello",
  "version": "0.1.0",
  "description": "在命令面板里向 BeefTV 问好",
  "type": "module",
  "keywords": ["beeftv-plugin"],
  "beeftv": {
    "name": "问好",
    "client": "./client.js"
  }
}
```

`client.js`：

```js
export function activate(host) {
  host.contribute("app.command", {
    id: "hello",
    label: "向 BeefTV 问好",
    onSelect: () => host.ui.notify("你好，BeefTV！", "success"),
  });
}
```

**2. 安装。** 打开插件中心，点「安装插件」，选「本地插件目录」，填这个文件夹的完整路径，点「下一步」，核对信息后确认安装。

**3. 试一下。** 按 `Cmd+K`（Windows 和 Linux 上是 `Ctrl+K`）打开命令面板，输入“问好”，选中这条命令，就能看到“你好，BeefTV！”。

**4. 改代码。** 把问候语改一下，回到插件中心，点这个插件上的「重新加载」，再运行一次命令。不用重启 BeefTV，也不用改版本号。

`package.json` 写错时，重新加载会失败并逐条说明要改什么，原来装好的版本照常可用。

## 插件能做什么

下面这些可以写在同一个包里，用不上的不用写。

| 想做的事 | 写在哪里 | 说明 |
| --- | --- | --- |
| 加按钮、菜单、页面、侧栏 | `beeftv.client` | [界面挂点](./plugin-reference.mdx#界面挂点) |
| 加画布节点 | `beeftv.contributes.canvasNodes` 和 `beeftv.client` | [加一个画布节点](#加一个画布节点) |
| 给创作助手加工具 | `pi.extensions` | [给助手加一个工具](#给助手加一个工具) |
| 教创作助手一套做法 | `pi.skills` | [写一个技能](./skills.mdx) |
| 接入图片、视频、音频或文本服务 | `beeftv.contributes.providers` | [接入生成服务](./plugin-generation.mdx) |
| 让用户填设置 | `beeftv.configuration.fields` | [让用户填设置](#让用户填设置) |

一个功能齐全的插件长这样：

```text
beeftv-plugin-sticky-note/
├── package.json
├── client/index.js       # 浏览器里运行的界面代码
├── extensions/index.ts   # 创作助手的工具
├── skills/sticky-note/
│   └── SKILL.md          # 创作助手的技能
└── README.md
```

这个例子的完整代码在仓库的 `plugin-packages/beeftv-plugin-sticky-note/`。

## 加一个画布节点

节点要写两处：`package.json` 声明它的名字和尺寸，`client.js` 负责把它画出来。

```json
{
  "beeftv": {
    "name": "画布便签",
    "client": "./client.js",
    "contributes": {
      "canvasNodes": [
        {
          "id": "sticky-note",
          "label": "画布便签",
          "defaultTitle": "便签",
          "renderer": "client",
          "defaultSize": { "width": 240, "height": 180 }
        }
      ]
    }
  }
}
```

```js
export function activate(host) {
  const { createElement: h, useState } = host.React;

  function StickyNote({ node, updateNodeData }) {
    const [text, setText] = useState(node.metadata?.pluginData?.content ?? "");
    return h("textarea", {
      value: text,
      placeholder: "写点什么",
      style: { width: "100%", height: "100%", padding: "36px 14px 12px", border: "none", borderRadius: 10, background: "#fef08a", color: "#713f12", boxSizing: "border-box" },
      onChange: (event) => {
        setText(event.target.value);
        updateNodeData?.({ content: event.target.value });
      },
    });
  }

  // 告诉画布怎么画这种节点。
  host.contribute("canvas.node", {
    id: "sticky-note",
    type: "sticky-note",
    title: "画布便签",
    defaultSize: { width: 240, height: 180 },
    render: StickyNote,
  });

  // 在「添加节点」菜单里加一个入口。
  host.contribute("canvas.addNodeMenu", {
    id: "add-sticky-note",
    label: "画布便签",
    nodeType: "sticky-note",
    onSelect: (ctx) => ctx.handlers.onAddExtensionNode("sticky-note"),
  });
}
```

- `updateNodeData` 写入的内容保存在节点的 `metadata.pluginData` 里，随画布一起保存。
- 用 `host.React`，不要在插件里再带一份 React。
- 代码要直接写成浏览器能运行的 JS。BeefTV 不会替你编译，JSX 和 TypeScript 要先自己转好。

## 给助手加一个工具

创作助手的工具写在 `pi.extensions` 指向的文件里，写法和 pi 扩展相同。工具里用 `ctx.executeTool` 调用 BeefTV 的业务操作，工具名是操作 ID 把点换成下划线，比如 `canvas.nodes.create` 对应 `canvas_nodes_create`。权限模式、付费确认和整组撤销都照常生效。

```json
{
  "peerDependencies": {
    "@earendil-works/pi-coding-agent": "*",
    "typebox": "*"
  },
  "pi": {
    "extensions": ["./extensions/index.ts"]
  }
}
```

```ts
import type { ExtensionAPI } from "@earendil-works/pi-coding-agent";
import { Type } from "typebox";

export default function (pi: ExtensionAPI) {
  pi.registerTool({
    name: "sticky_note_create",
    label: "新建便签",
    description: "在当前画布上创建一张便签。",
    parameters: Type.Object({
      title: Type.String({ description: "便签标题" }),
      text: Type.String({ description: "便签内容" }),
    }),
    async execute(_id, params, _signal, _onUpdate, ctx) {
      const read = await ctx.executeTool("canvas_get", {});
      const readText = read.result.content.map((part) => ("text" in part ? part.text : "")).join("");
      if (read.isError) throw new Error(`读取画布失败：${readText}`);
      const revision = Number(/"revision"\s*:\s*(\d+)/.exec(readText)?.[1]);

      const created = await ctx.executeTool("canvas_nodes_create", {
        expectedRevision: revision,
        nodes: [{ type: "sticky-note", title: params.title, prompt: params.text }],
      });
      if (created.isError) throw new Error("创建便签失败");
      return { content: [{ type: "text", text: `已创建便签「${params.title}」` }], details: { revision } };
    },
  });
}
```

装好或重新加载后，助手从下一轮对话开始就能用这个工具。

## 让用户填设置

在 `beeftv.configuration.fields` 里列出字段，插件中心会多一个设置窗口。

```json
{
  "beeftv": {
    "configuration": {
      "fields": [
        { "name": "greeting", "type": "string", "label": "问候语", "default": "你好" },
        { "name": "tone", "type": "select", "label": "语气", "values": ["正式", "轻松"] }
      ]
    }
  }
}
```

界面代码用 `host.config.get("greeting")` 读取。字段类型见[插件参考](./plugin-reference.mdx#设置字段)。

这些设置只有界面代码读得到。生成服务的地址和 Key 不放在这里，放在用户的模型服务里，见[接入生成服务](./plugin-generation.mdx)。

## 发布

1. 确认 `keywords` 里有 `"beeftv-plugin"`，然后运行 `npm publish --access public`。用户在插件市场的「npm 社区搜索」里就能搜到并安装。
2. 想进精选列表，向 [Sunnyender-org/beeftv-plugins](https://github.com/Sunnyender-org/beeftv-plugins) 提一个 Pull Request，在 `registry.json` 的 `packages` 里加一行包名。名称、说明、版本和作者都从 npm 读。
3. 发新版本只要再运行一次 `npm publish`。用户的插件中心会显示「更新到 v新版本」，由用户自己决定要不要更新。

收录进精选列表不代表 BeefTV 为插件担保。用户安装任何插件前，BeefTV 都会显示来源和风险，由用户确认。

没有发布到 npm 也能分享：「npm 插件包」的输入框还可以填 `github:owner/repo` 或一个 `.tgz` 地址。
