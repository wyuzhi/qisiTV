# qisiTV v1.5.11 上游同步

本次检查上游 `glanderness/BeefTV` 至 v1.7.15（`bb8d5b83`）。相对于上次检查点 `06e7680`，上游增加 97 个提交、改动 698 个文件；其中包含嵌入式 Agent、账户、模型渠道及桌面后端的大规模调整。

图片强制重新下载仅用于 `resource:` 远程缓存；本机 `image:` 资源继续通过本地文件读取，重试不等于修复已损坏的原始文件。页面关闭时的异步文件写入只能尽力完成，退出前仍应确认画布显示已保存；关闭浏览器不会把 IndexedDB 变成最终项目持久化。

未合并上游内置 Agent、账户与钱包、新服务商、桌面更新器、FFmpeg 后端及导演台整体迁移；这些依赖不同的运行时或不属于当前产品范围。没有执行真实付费生成。

## 验证

通过 204 项专项测试：

- 键盘与 Agent 三路合并：27 项。
- 本地仓库、目录、MCP、双 API、备份导入与生成保存：69 项。
- 音频参数、媒体交互合同、任务进度和滚轮：73 项。
- 引用编辑器：14 项真实 Chromium 交互与 11 项相邻合同测试。
- 图片缓存恢复与连续滚轮：2 项真实浏览器测试，覆盖明暗主题、390px 窄窗口、请求失败、解码失败和同一资源的并发恢复。
- 离开保存：8 项真实生命周期 hook 浏览器测试，覆盖页面隐藏、卸载、手动保存、A→B 切换、失败保留、无改动不写及待写队列去重。

TypeScript 检查、`VITE_QISITV_BROWSER_ONLY=1 QISITV_WEB_BASE=/qisitv/ bun run build` 和 `git diff --check` 通过。生产构建仍有既存的大 chunk 提示；本次不改造全站分包。

独立复核补齐了只读输入框退格防护，并修复两个继承问题：重复离开事件造成无效文件版本，以及同一远程图片并发重载时相互撤销 Blob URL。引用删除后的异步光标恢复竞争也由真实浏览器回归复现并修复。

测试只使用本地夹具和模拟任务响应。离开保存测试运行真实生命周期 hook，但替换目录仓库与浏览器缓存依赖；磁盘契约另由目录模拟测试覆盖，不冒称完成真实操作系统目录授权验收。未提交真实付费生成。
